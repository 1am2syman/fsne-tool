# Task: translate Excel Power Query queries to Polars

Goal: Translate all eight queries in `queries/` into chained native Polars scripts in `src/`, resolving input and output paths with pathlib relative to the repository.

Plan: original query translations plus an explicitly inferred final report; complete sample comparison, Excel export, independent boundary tests and final acceptance-gate verification.

Decisions: sample_input/ and sample_output/sample_output.xlsx are now supplied; preserve them unchanged. The reference workbook is a final 30-column report, not any of the eight individual query outputs. The user explicitly authorized inference of the missing final calculation rules. Matching the supplied dataset is not proof of original-formula equivalence on other periods. Preserve recursive folder matching and combined-header promotion. Preserve differing batch-key whitespace behavior in soh_db and sec_history. Compute run-rate averages as grouped monthly sums divided by global distinct month count (zero-filled pivot equivalent). Excel sheets and named tables are read with Polars plus openpyxl at the workbook metadata boundary.

Progress: src/report.py generates all 30 final columns from sample_input only. Final full comparison matches all 27,891 rows / 836,730 cells, row order and null placement within floating tolerance; Excel roundtrip passes. All supplied inputs and reference remain unchanged by SHA-256. src/compare_report.py writes output/inferred_report.xlsx, Parquet, per-column comparison.csv, comparison.json integrity checks, and supported current_measures.json. Native Excel landing-rate precision and Mon-YYYY secondary date parsing fixed. Twenty-two unit/integration tests pass; Ruff and project-configured Pyright pass. Some harness LSP imports were false positives from its stale environment. GATES.md and INFERENCE_GATES.md both pass: six gates met, zero unmet or abandoned. Full comparison evidence is in output/comparison.json and output/comparison.csv; maximum observed cell error is 9.313225746154785e-10.

Inferred rules: child-material/town queues; independent capped fractional DOH durations accumulate before truncating absolute Excel date serials; 300-day reserves for 1x/2x consumption, 90-day reserve for forecast; missing rates imply full consumption beyond reserve. Valuation uses NOS × native material landing rate. Full derivation, nonpositive/nonfinite input rejection, duplicate/tie extrapolations and unavailable historical screenshot measures are in docs/inference.md. No reference data is used to generate rows. Next: user can regenerate using `uv run python -m src report --data-dir sample_input --output output/inferred_report.xlsx`; validate another independent period or obtain original formulas before claiming general business-rule equivalence.

Safety: do not modify original queries or existing unrelated files; no row-wise Python transformation UDFs; no hardcoded absolute machine paths.
